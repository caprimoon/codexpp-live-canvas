# LiveCanvas · 动态壁纸与毛玻璃

为 **Codex++** 桌面端打造的沉浸式动态壁纸与毛玻璃工作台拓展：提供五大在线视频壁纸聚合图库、本地视频与图片导入、离线低负载动态场景，以及面向左侧栏 / 对话内容区 / 底部输入框的三区独立色彩与毛玻璃调节能力。

---

## 核心功能

### 1. 五源高清动态图库 + 离线内置场景
- **五大片源聚合**：接入 Mixkit（实拍 / 抽象素材为主）、MoeWalls、MotionBgs、WallpaperWaifu 与 LiveWallpapers4Free，支持跨源聚合浏览、分类筛选、英文关键词检索、分页与收藏。
- **离线内置场景**：内置「深蓝雨幕」「远航星空」「代码之雨」三个低负载 Canvas 动态场景，无网也能随时使用。
- **本地媒体与直链**：支持导入 256 MB 以内的本地 `MP4` / `WebM` / `GIF` / `PNG` / `JPG` / `WebP` 文件（分片上传 / 复制到拓展专属数据目录，不压缩不转码），也支持应用媒体直链。

### 2. 三区面板色彩与毛玻璃体系（1/2/3 分区）
- **原生取色器配置三区底色**：在「显示设置」中使用系统原生颜色选择器直接调整，实时预览并自动保存：
  - **1 · 左侧栏颜色**（默认 `#232323`）
  - **2 · 对话内容区颜色**（默认 `#232323`；发送气泡基于所选底色自动微调对比度以保持区分）
  - **3 · 底部输入框颜色**（默认 `#4A4A4A`）
- **统一 / 分区独立双模式**：
  - 默认统一调节 **面板遮罩（0%–100%，100% 完全不透明）** 与 **玻璃模糊（0–24px，0px 关闭 `backdrop-filter`）**。
  - 开启 **「1/2/3 三区独立调节遮罩与模糊」** 开关后，无缝继承当前数值并展开三组独立滑块，分别控制侧栏、对话区与输入框的不透明度和虚化强度。

### 3. 右侧推开式抽屉与画面深度融合
- **单一入口不打扰**：通过 Codex 左侧导航栏「动态壁纸」图标展开约 1/3 窗口宽度的右侧抽屉，再次点击图标、点击关闭按钮或切换其他导航入口即可收起并熄灭高亮；图库浏览与所有显示设置集中收归其中。
- **无黑边画面适配**：默认「填满整窗 · 按最短边等比铺满（不留黑边）」，支持调整主体横向 / 纵向裁切重心（0%–100%），亦可选「完整显示」或「拉伸铺满」。
- **原生外观兼容**：自动清除设置页、拓展页及滚动会话区顶部残留灰条与滚动阴影，保留回复卡片 `18px` 协调内边距与圆角质感。
- **性能保护**：支持视频优先级（`auto` / `preview` / `hd` / `2k` / `4k`）、播放倍速、定时随机轮换、窗口不可见时自动暂停与系统“减弱动态效果”兼容。

## 默认配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 背景遮罩 | `30%` | 壁纸上层压暗遮罩 |
| 背景模糊 | `0px` | 壁纸本身高斯模糊 |
| 1/2/3 独立调节开关 | `关闭` | 关闭时三区联动，开启后分别设置 |
| 面板遮罩 | `50%` | 支持 `0%` 全透至 `100%` 全不透 |
| 玻璃模糊 | `12px` | `backdrop-filter` 虚化强度（`0px` 关闭） |
| 1 · 左侧栏颜色 | `#232323` | 左侧项目与导航面板底色 |
| 2 · 对话内容区颜色 | `#232323` | 回复卡片底色（用户气泡自动微调对比） |
| 3 · 底部输入框颜色 | `#4A4A4A` | 输入栏与首页工具条底色 |
| 画面适配 | `填满整窗（cover）` | 按最短边等比铺满，不留黑边（重心 `50% / 50%`） |
| 视频画质 / 倍速 / 轮换 | `自动 1080p` / `1×` / `关闭` | 不可用高清自动回退预览版 |

## 安装与使用

### 方式一：下载 Release 安装包（推荐）

1. 前往 [Releases](https://github.com/caprimoon/codexpp-live-canvas/releases) 下载 `live-wallpaper-studio-v1.0.0.zip`（请优先下载构建好的 ZIP 压缩包，勿直接使用 GitHub 的 `Source code`）。
2. 解压至 Codex++ 的用户拓展目录下，确保文件夹名称为 `live-wallpaper-studio`，根目录直接包含 `codexpp.json`：
   - **Windows**：`%APPDATA%\Codex++\user_scripts\live-wallpaper-studio\`
   - **macOS**：`~/.config/Codex++/user_scripts/live-wallpaper-studio/`
3. 打开 **Codex++ 管理器 → 拓展 → 本地拓展**，点击刷新并启用 **LiveCanvas · 动态壁纸与毛玻璃**，再点击 **热重载拓展**。
4. 在 Codex 左侧图标栏点击 **「动态壁纸」** 即可打开右侧壁纸与设置抽屉。

更多手动部署细节、目录结构、数据路径与故障排查见 [部署与使用指南](docs/使用指南.md)。

## 数据、权限与边界

- **无侵入边界**：无模型工具、无网关中间件、无遥测上报，不读取或上传 Codex 会话正文、提示词或本地代码路径；扩展运行需依赖 Codex++ 页面注入与 Node 常驻后台。
- **网络与素材边界**：仅在浏览在线图库或应用在线直链/下载缓存时请求对应视频源；本地导入媒体仅复制到本机 `%APPDATA%\Codex++\extension-data\live-wallpaper-studio\`（macOS 为 `~/.config/Codex++/extension-data/live-wallpaper-studio/`）。在线素材版权与使用条款以各原站声明为准。
- **环境说明**：已在 Windows 桌面端实际验证；macOS 目录结构按 Codex++ 规范适配，尚未在真机实测。
